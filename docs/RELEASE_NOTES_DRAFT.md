## 新功能

- 新增本机 Token 用量统计：菜单查看近七日图表，点开查看历史明细、输出速度和已用量的 API 等值。
- 保活可以单独开关，关闭后仍可查看额度、使用自动续跑。

## 修复

- 优化后台资源占用，减少重复读取，历史详情按需加载。
- 修复部分情况下用量统计停止刷新的问题；每小时自动更新，点击刷新也能立即更新本机用量。
- 改善压缩会话记录的识别，修正额度耗尽、读取失败和周额度提前重置时的部分提示。
