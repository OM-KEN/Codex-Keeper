# Codex Keeper

[English](README.en.md)

一个安静待在菜单栏里的 Codex 小助手。

- **保持活动**：按你设置的时间，尝试开启新的 5 小时额度窗口。
- **自动继续**：任务因额度用完而暂停后，确认额度正常恢复时尝试继续；提前恢复或恢复情况不明时，先提醒你选择。
- **查看额度**：随时查看 5 小时和每周额度，以及下一次操作时间。

## 使用条件

Apple Silicon Mac（M 系列芯片），macOS 13 或更新版本。先安装 Codex，并登录 ChatGPT 账户。

目前为测试版，主要适用于本机 Codex 任务；保持活动需要账户可使用 `gpt-5.6-luna`。Keeper 不会增加额度，也不会绕过额度限制。

## 怎么用

1. 从 [GitHub Releases](https://github.com/OM-KEN/Codex-Keeper/releases/latest) 下载 DMG，打开后将 **CodexKeeper** 拖入 **Applications（应用程序）**，再打开它。
2. 首次打开时按引导选择每日开始时间，点击“开始使用”。例如选择 `08:00`，计划预览为 `08:00 · 13:00 · 18:00 · 23:00`。
3. Keeper 默认开启保持活动和自动继续，之后可在菜单栏设置中调整或关闭。
4. 出现待续任务后，点击菜单中的任务名称，可选择任务并修改发送内容；需要你决定时，点击菜单最顶部提醒中的“处理任务”。

提醒也会通过系统通知发送，可选择“现在继续”“按计划继续”或“取消本次”。尚未重新使用 Codex 时，提醒一直保留；确认你已再次使用后，10 分钟未选择会取消本次自动续跑，原任务和历史保留。等待决定不会影响 Keeper 保活。

Codex 桌面应用可以关闭；Keeper 自己仍需运行，且 Mac 要保持醒着并联网。已有有效额度窗口时会跳过保活；停用 Keeper 可暂停自动操作。

界面支持简体中文和英语，跟随 macOS 的应用语言设置。已自定义的续跑发送内容不会因切换语言而改写。
设置中的默认续跑内容可选随界面语言变化的“继续”或在弹窗中编辑自定义内容。
项目文件变化或无法核对时，Keeper 默认在续跑内容前单独附加检查提醒；可在设置中关闭。

安装包未公证。如果首次打开被系统拦截，确认下载来源后，可参考 [Apple 的打开说明](https://support.apple.com/zh-cn/102445)。

同步失败时，可点击时间区右侧的刷新按钮；持续失败则检查网络、Codex 登录和版本。
