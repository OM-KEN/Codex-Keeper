# Codex Keeper

[English](README.en.md)

**定时启动额度窗口，额度恢复后自动续跑。**

一个运行在 macOS 菜单栏里的 Codex 小工具：

- **提前启动额度计时**：按你设置的每日计划，在用 Codex 前启动 5 小时额度窗口，方便按自己的作息安排使用。
- **额度恢复后自动续跑**：任务因额度用完而暂停后，确认额度正常恢复就会自动继续。
- **随时查看额度**：在菜单栏查看 5 小时和每周剩余额度，以及下一次保活或续跑时间。

## 使用条件

Apple Silicon Mac（M 系列芯片），macOS 13 或更新版本。先安装 Codex，并登录 ChatGPT 账户。

目前为测试版，适用于本机 Codex 任务。定时保活需要账户可使用 `gpt-6-luna`；Keeper 不会增加额度或绕过额度限制。

## 怎么用

1. [下载安装包](https://github.com/OM-KEN/Codex-Keeper/releases/latest)，将 Codex Keeper 拖入「应用程序」并打开。
2. 设置每日开始时间，点击「开始使用」。

保活和自动续跑默认开启。点菜单栏图标即可查看额度、任务和设置。

使用时保持 Keeper 运行，Mac 保持唤醒并联网。

## 常见问题

<details>
<summary>任务暂停后，什么时候会自动继续？</summary>

因额度用完而暂停的任务，确认额度正常恢复后会自动继续。提前恢复或恢复情况不明时，会提醒你选择。

点击菜单顶部提醒中的“处理任务”，或通过系统通知选择：

- **现在继续**：确认额度和任务状态后尝试继续。
- **按计划继续**：在下一个可行的计划时间尝试继续，发送前再次确认额度和任务状态。
- **取消本次**：跳过本次续跑，保留原任务和历史。

未选择时，提醒一直保留，该任务不会自动继续；Keeper 仍按计划保活。

</details>

<details>
<summary>可以修改续跑时发送的内容吗？</summary>

点击菜单中的任务名称，可选择待续任务并修改发送内容，也可使用该任务在 Codex 中已保存的输入框草稿。

设置中可选择默认发送“继续”，或编辑自定义内容。界面支持简体中文和英语，跟随 macOS 的应用语言设置；默认内容随语言变化，自定义内容保持原样。

项目文件变化或无法核对时，Keeper 默认在续跑内容前附加检查提醒，提醒 Codex 先核对项目和进度；可在设置中关闭。

</details>

<details>
<summary>打不开或额度同步失败怎么办？</summary>

安装包未公证。如果首次打开被系统拦截，确认下载来源后，可参考 [Apple 的打开说明](https://support.apple.com/zh-cn/102445)。

同步失败时，点击时间旁的刷新按钮；持续失败则检查网络、Codex 登录和版本。

如果提示找不到官方 Codex CLI，点击菜单中的错误提示，填写或选择可执行文件，再点“保存并重试”。支持 `~/` 和带空格的路径。只有自动查找失败时才需要填写。

</details>

<details>
<summary>如何检查更新或反馈问题？</summary>

点击菜单中「设置…」下面的版本号，打开关于页，查看应用图标和版本、检查更新，或选择邮件 / GitHub 反馈。

更新提醒默认开启。发现新版时，版本号后会显示「有新版本」和绿色向上箭头；进入关于页后，点击「前往 GitHub 更新」下载新版。关于页可关闭更新提醒，也可随时手动检查。

</details>
